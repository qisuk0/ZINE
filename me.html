首次使用：启用本地 AI 服务

在项目目录打开 PowerShell，设置你自己的 API 密钥并启动后端；不要把密钥写进网页或发送到聊天中。

$env:OPENAI_API_KEY="你的 API 密钥"
python local_server.py

生成时，本月日记内容会发送至 OpenAI API。API 密钥仅保存在后端环境变量中。

首次使用：启用 AI 服务

线上版（Netlify）：在站点后台 Site configuration → Environment variables 添加 OPENAI_API_KEY，保存并重新部署即可，无需本地运行任何程序。

本地版：在项目目录打开 PowerShell，设置你自己的 API 密钥并启动后端；不要把密钥写进网页或发送到聊天中。

$env:OPENAI_API_KEY="你的 API 密钥"
python local_server.py

启动后请通过 http://127.0.0.1:8765/me.html 打开此页面。
